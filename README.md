# News Project

## Description
This is a Django-based news application with role-based access control. The system supports Readers, Journalists, and Editors with different permissions for articles and newsletters.

## Features

### Reader
- View published articles
- View newsletters
- Subscribe to publishers
- Subscribe to journalists

### Journalist
- Create articles
- Edit articles
- Delete articles
- Create newsletters
- Edit newsletters
- Delete newsletters

### Editor
- View drafts
- Publish articles
- Edit articles
- Delete articles
- Manage newsletters

## Technologies Used
- Python
- Django
- MariaDB / MySQL
- HTML
- CSS

## Project Structure
- `config/` - Project configuration
- `newsapp/` - Main Django application
- `Planning/` - Design documentation
- `manage.py` - Django management file
- `requirements.txt` - Project dependencies
